# When to use

- Create a pull request for GitHub under this repo

# Instructions

The PR should have the following information.
```
## Header

It should follow the pattern
`feat(transaction): support transaction type`

## Body

### Summary

This PR implements a transaction type feature.

Fixes #1234

### Change Type

- [x] Feature
- [ ] Bugfix
- [ ] Document
- [ ] Enhancement
- [ ] Development Tools

### Test Coverage

```

- Header should be categorized into feat, fix, doc, or tool
